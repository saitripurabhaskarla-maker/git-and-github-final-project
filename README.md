Simple Interest Calculator
Description

This is my final project submission for the GitHub course. It is a simple program that calculates Simple Interest based on three user inputs: Principal amount, Rate of interest, and Time period (in years).

Formula Used

Simple Interest (SI) = (P × R × T) / 100

Where:

P = Principal amount (the initial amount of money)
R = Annual rate of interest (in %)
T = Time period (in years)
How It Works
The user enters the principal amount.
The user enters the annual interest rate.
The user enters the time period in years.
The program calculates and displays the simple interest and the total amount (Principal + Interest).
Example
Enter Principal Amount: 1000
Enter Rate of Interest (%): 5
Enter Time Period (years): 2

Simple Interest = 100
Total Amount = 1100
